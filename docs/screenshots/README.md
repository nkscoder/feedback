# Screenshots for README & PyPI

| File | Used in |
|------|---------|
| `feedback-form.png` | User feedback form (Bootstrap example) |
| `ai-dashboard.png` | Staff AI analytics dashboard |

## Update screenshots

1. Run your Django project with `feedback` installed.
2. Capture the form page and `/feedback/dashboard/` (staff login).
3. Save as PNG (recommended width 1280px) and overwrite files here.
4. Commit and push — images appear on GitHub README automatically.
